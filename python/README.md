# J.A.R.V.I.S. (Python — full features)

Full copy of [Mark-LIII](https://github.com/FatihMakes/Mark-LIII) by FatihMakes (CC BY-NC 4.0), customized prompt for MCU JARVIS.

## Quick start (Windows)

```bat
cd path\to\JARVIS\python
python setup.py
```

Put Gemini key in `config/api_keys.json`:

```json
{
  "gemini_api_key": "YOUR_KEY_FROM_https://aistudio.google.com/apikey",
  "os_system": "Windows",
  "assistant_name": "JARVIS",
  "user_name": "sir"
}
```

Then:

```bat
python main.py
```

See SETUP_AASHISH.md for details.
